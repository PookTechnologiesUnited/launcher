# Contribution Guidelines

Hello. If you are thinking of contributing to this repository, please first refer to these guidelines.

To achieve the goal of having the BEST repository in the world,
current and future contributors must follow the general rules.

## General Rules

1. CODE OF CONDUCT must be the #1 priority.
2. All issues regarding the code and/or functionality must be described in GitHub's Issue Tracker of this very repository.
3. Otherwise, contact me!

## Creating Issues

If you are experiencing some sort of issue with the end-user product, for this repository being Wauncher and its side products, feel free to create an issue on GitHub or directly file a report to my mail: github@koolych.ru.

Guidelines:

- Avoid creating issues similar to an existing or resolved issues
- Describe your issue as detailed as possible, so that contributors know what to fix in the most effective way
- Your issue title must be descriptive, don't use generic stuff, for example, "X doesn't work", "Suggestion Y".

## Creating Pull Requests

Any contribution is welcome. Please retract from editing the stuff that is relevant only for the repository, such as LICENSE, CONTRIBUTING and automated stuff.

Hope this helps for now. Happy contributing!
